# principality-frontend

SPA «Удельные княжества Древней Руси»: плитка и лента княжеств с археологически измеренной площадью укреплений. Бэкенд — [principality-backend](https://github.com/dehwyy/principality-backend).

React 19 + TypeScript + Vite, React-Bootstrap, react-router-dom. В лабораторной 5 данные берутся из mock-объектов, запросов к бэкенду нет.

## Запуск

```bash
npm install
npm run dev
```

Приложение открывается на `http://localhost:3000`, корень перенаправляет на `/principalities`.

## Страницы

### Плитка `/principalities`

- Поле «Основано до» — дата (`input type="date"`), по ней фильтруются княжества с `founding_date` не позднее выбранной.
- Кнопка «Найти» — применяет фильтр; при пустом поле показываются все княжества, при пустом результате — «К сожалению, пока ничего не найдено :(».
- Карточка княжества — изображение (или `/DefaultImage.jpg`, если у княжества его нет), счётчик лайков, название, год основания, плашка «коэф. земли». Нажатие на карточку открывает ленту с этого княжества.

### Лента `/principalities/feed/:id`

- Видео княжества во весь экран (или `/DefaultVideo.mp4`, если у княжества его нет).
- Поля «основано» (год) и «коэф. земли», счётчик лайков.
- Кнопка «Далее» — следующее княжество из текущего отфильтрованного списка, с последнего возвращается к первому.
- Название и описание княжества; кнопка «Больше» / «Меньше» разворачивает и сворачивает описание.

## Меню

Нижняя панель из четырёх пунктов: «Лента», «Добавление», «Плитка», «Вход». «Лента» открывает первое княжество текущего списка плитки. «Добавление» и «Вход» недоступны до подключения бэкенда и авторизации.

## Данные

- `src/modules/principalitiesApi.ts` — тип `Principality`, поля совпадают с JSON бэкенда.
- `src/modules/mock.ts` — `PRINCIPALITIES_MOCK`, восемь опубликованных княжеств из сида бэкенда.
- `public/principality-media/` — изображения и видео княжеств, `public/DefaultImage.jpg` и `public/DefaultVideo.mp4` — заглушки.
